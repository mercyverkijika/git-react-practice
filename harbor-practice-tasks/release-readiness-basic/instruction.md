# Release Readiness Task

You are helping a release manager decide whether version 2.1 is ready to release.

Review the following files:

- environment/release_checklist.md
- environment/ci_summary.txt
- environment/known_issues.md

Create a file called:

- release_decision.md

Your output must include:

1. A final decision: READY or NOT_READY
2. Exactly three evidence-backed reasons
3. A short recommendation for the release manager

Do not ignore blocker issues.
Do not invent evidence that is not present in the files.

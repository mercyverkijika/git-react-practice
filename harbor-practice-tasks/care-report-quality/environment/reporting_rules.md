# Weekly Reporting Rules

The weekly care visit report can be sent to management only if all of the following are true:

- No unresolved critical data quality exceptions remain.
- Each completed visit must have an actual_start and actual_end timestamp.
- Duplicate visit records must be resolved before reporting.
- Closed minor exceptions do not block reporting.

If unresolved critical exceptions, missing critical timestamps, or duplicate visit records remain, the report must not be sent.

# Care Report Quality Task

You are helping an operations manager decide whether a weekly care visit report is reliable enough to send to management.

Review the following files:

- environment/visit_summary.csv
- environment/exception_log.md
- environment/reporting_rules.md

Create a file called:

- report_readiness_decision.md

Your output must include:

1. A final decision: READY or NOT_READY
2. Exactly three evidence-backed reasons
3. A short recommendation for the operations manager

Do not approve the report if unresolved critical data quality issues remain.
Do not invent evidence that is not present in the files.
